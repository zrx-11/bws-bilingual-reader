# BWS 数学证明写作 · 双语学习网页

Brendan W. Sullivan《Mathematical Writing》(CMU 2013) 的离线双语学习工具。

## 功能

七个模块，单 HTML 文件，离线双击即开：

1. **双语电子书** — 全书 5031 段逐段中英对照，带独立悬浮目录抽屉
2. **知识骨架** — 333 个双语核心知识点，每个可点击跳回原文页码
3. **逐页导学** — 9 章 63 节，带原文页码标注
4. **术语表** — 130 条标准数学术语（induction=归纳法、bijection=双射、cardinality=基数等）
5. **行动规则** — 69 条写作与证明技巧
6. **自检** — 47 道四选项题，答错自动跳回原文重看
7. **笔记** — localStorage 本地存储，不联网不上传

## 使用

直接双击 `index.html` 在浏览器中打开即可。

- 不需要联网
- 不需要账号
- 笔记和错题只存在你本地浏览器里

手机端已适配，左右滑动不会溢出。

## 技术栈

- 纯 HTML/CSS/JS，零依赖
- 所有数据内嵌在单个 HTML 文件中（约 2.7 MB）
- 响应式布局，手机/桌面均可使用
- 数据持久化使用 localStorage

## 目录结构

```

    ├── build_html.py       # HTML 构建脚本
    └── bws_chapters/       # 原始章节数据

        └── ebook_merged.json
```

## 重新构建

如果你想从数据重新生成 HTML：

```bash
cd src
python3 build_html.py
```
